# Oriel for macOS — Plan

Native port of [oriel-windows](../oriel-windows-public) (WinUI 3 / C#) to macOS.
Version 1 scope: **wallpaper, history, settings**. Account, sync and social features come later.

## Decisions

| Topic | Decision |
| --- | --- |
| Stack | Swift 6 + SwiftUI, native |
| Minimum OS | macOS 26 Tahoe (Liquid Glass, latest SwiftUI) |
| Account in v1 | None: the app works signed out (Windows requires sign-in) |
| Unsplash key | A **separate Unsplash app** for macOS (own rate limit). Apply for production access before release |
| Dropped features | Tile fit, lock screen, system accent color (no macOS API) |
| Distribution | `.dmg` download, no App Store, no paid Apple Developer account |
| Signing | Free self-signed certificate (a stable identity keeps Keychain access working across updates). Users approve the first launch via System Settings → Privacy & Security → Open Anyway |
| Updates | Sparkle, EdDSA-signed, feed and DMGs on GitHub Releases |
| Repos | Private source repo + public `oriel-releases/macos` holding only releases |

## Architecture

- **OrielKit**: a Swift package with no UI, the equivalent of `Oriel.Core`, unit-tested with Swift Testing. An optional auth hook from day one, so phase 2 slots in.
- **Oriel.app**: a SwiftUI menu bar app (`LSUIElement`; Dock icon only while the window is open).
- **Project**: generated by XcodeGen from `project.yml`, built with `xcodebuild` (no hand-edited Xcode project files).
- **Storage**:
  - `~/Library/Application Support/Oriel/`: `settings.json`, `state.json` (same format as Windows), `oriel.db` (SQLite via GRDB, same `history` table), `logs/`
  - `~/Pictures/Oriel`: photos
- **Unsplash key**: `UNSPLASH_ACCESS_KEY` from the environment or `.env`, embedded at build time.

## Windows → macOS mapping

| Windows | macOS |
| --- | --- |
| SystemParametersInfo / IDesktopWallpaper | `NSWorkspace.setDesktopImageURL` per `NSScreen` |
| Fill / Fit / Stretch / Center | `imageScaling` + `allowClipping` options |
| Span | Oriel crops the photo into one piece per screen |
| All virtual desktops | Re-apply on `activeSpaceDidChangeNotification` |
| Tray icon (H.NotifyIcon) | `MenuBarExtra` |
| Run key + Task Scheduler | `SMAppService.mainApp` (login item); the app is always running |
| Efficiency mode | Background QoS / App Nap |
| App SDK toasts | `UNUserNotificationCenter` with Keep / Skip / Favorite actions |
| RegisterHotKey | KeyboardShortcuts package |
| Registry theme | `NSApp.effectiveAppearance` |
| Velopack | Sparkle |
| DPAPI (phase 2) | Keychain |
| `oriel://` in the registry (phase 2) | `CFBundleURLTypes` |

## Milestones

### M0 — Setup
- Install Xcode (App Store) and XcodeGen (`brew install xcodegen`).
- Create the repo skeleton (package + app target), embed the Unsplash key, create the self-signed certificate.

### M1 — OrielKit core
- Models, settings and state stores (built-in topics, daily time, time zone).
- Unsplash provider: random candidates, download at screen size, download-tracking ping.
- Candidate filter, time-of-day mood, never-repeat, retention, wallpaper folder mover.
- Port the relevant xUnit tests.

### M2 — Wallpaper engine
- Wallpaper setter: per screen, fit modes, Span cropping, re-apply on Space switch.
- WallpaperService: pick → download → set → record. The download finishes before the desktop changes; prefetch the next photo.
- Retries with backoff (2m → 5m → 15m → 30m → 1h) and the "Change now" per-hour limit.
- Scheduler: daily time or interval, at most a 10-minute sleep, wake / clock-change / screen-change handling.

### M3 — User interface
- Menu bar panel: current photo + credit, Next, Pause, Open, Quit.
- Main window (Liquid Glass, sidebar):
  - **Home**: current photo, Change now, Wallpaper of the day.
  - **History**: grid, re-apply, favorite, delete, show in Finder.
  - **Interests**: topic tiles, custom searches, excluded keywords.
  - **Settings**: schedule, fit, per-screen photos, quality filters, folder, open at login, hotkey, notifications, updates.
- Short first-run onboarding.

### M4 — System integration
- Login item, notifications with actions, hotkey, "changing…" popup.
- CLI flags (`--status`, `--change-now`).

### M5 — Release
- Self-signed codesign, DMG via `create-dmg`, Sparkle appcast.
- `scripts/release.sh` (build → sign → DMG → upload to `oriel-releases/macos`).
- Mac download page on the website with the Open Anyway guide.

## Later phases

- **Phase 2 — Account & sync**:
  - `oriel://` scheme, Keychain account store, port `FirebaseClient` (plain REST).
  - Settings and favorites sync, pulse listener (SSE via `URLSession.bytes`).
  - Backend: add `platform: "macos"`; the website sign-in hands off to `oriel://` on Mac.
- **Phase 3 — Social**: share links, follow / followers, collections, share sheet (`NSSharingServicePicker`).
